# Beat-Matching Games

Godot repositories for DDR, Taiko, osu!mania, and other note-timing rhythm games.

Last reviewed: 2026-06-20.

## Taiko and DDR Style

| Repository | Inspired by | Notes |
|---|---|---|
| [v-pukman-gd/godot-taiko](https://github.com/v-pukman-gd/godot-taiko) | Taiko no Tatsujin | CC0 Taiko drum clone in Godot with songs, notes, drum inputs, scoring, controls, and menus. |
| [gdquest-demos/godot-2d-rhythm](https://github.com/gdquest-demos/godot-2d-rhythm) | 2D rhythm game | GDQuest Godot 2D rhythm demo; playable project lives under the `godot` folder. |
| [TheDevRatt/Rhythm-Game](https://github.com/TheDevRatt/Rhythm-Game) | Rhythm game | Godot 4 rhythm game with scenes, scripts, songs, sounds, sprites, and export presets. |
| [harrypujols/rhythm-game](https://github.com/harrypujols/rhythm-game) | Rhythm game | Godot rhythm game with interface, rooms, scripts, fonts, and project source. |
| [HaMM4R/RhythmTrainGodot](https://gitlab.com/HaMM4R/RhythmTrainGodot) | Rhythm game | GitLab-hosted Rhythm Train project with addons, assets, scenes, Android files, and project source. |
| [najmam/game-disco-seducium](https://gitlab.com/najmam/game-disco-seducium) | Rhythm minigames | GitLab-hosted Ludum Dare rhythm minigame collection; Godot source lives under the `godot` folder. |
| [MikePowerhack/didactic-succotash](https://github.com/MikePowerhack/didactic-succotash) | Rhythm game | Small Godot rhythm-game project; source lives under the `rhythm_game` folder. |
