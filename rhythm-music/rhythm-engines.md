# Rhythm Engines and Frameworks

Reusable Godot rhythm systems covering chart loading, judgment windows, scoring, and beat synchronization.

Last reviewed: 2026-06-20.

| Repository | Notes |
|---|---|
| [yKoihsU/Godot-RhythmGameCore](https://github.com/yKoihsU/Godot-RhythmGameCore) | MIT-licensed lightweight Godot rhythm game framework covering chart synchronization, judgment timing, and scoring architecture. |
| [scenent/gd-rhythm](https://github.com/scenent/gd-rhythm) | Godot 4.0.1 rhythm sample system with generated notes, long notes, judgment windows, autoplay, and combo tracking. Good reference for judgment implementation. |
| [Dark-Peace/BulletUpHell](https://github.com/Dark-Peace/BulletUpHell) | Not a rhythm game, but the most-starred Godot shmup/bullet engine (366★); useful if building a beat-synced bullet-hell hybrid. Researched attacks from Enter the Gungeon and Binding of Isaac. Godot 3 and 4. |
