# Vertical Shmups

Godot repositories for 1942, Raiden, Touhou, and top-scrolling space shooters.

Last reviewed: 2026-06-20.

| Repository | Inspired by | Notes |
|---|---|---|
| [stphung/continuum](https://github.com/stphung/continuum) | Vertical shmup | Open-source vertical scrolling shmup built with Godot 4.4; features dual weapon systems, wave-based progression, and procedurally generated audio. |
| [Firstject/godot-space-rpg](https://github.com/Firstject/godot-space-rpg) | 1942 / Gun Nac | WIP 8-bit space shooter RPG in Godot inspired by NES/Famicom games like Star Force, 1942, and Gun Nac. |
| [FeatheredSnek/tsp](https://github.com/FeatheredSnek/tsp) | Touhou | Dota-themed Touhou-style game made in Godot 3.2.1; bullet patterns and boss spell mechanics. |
| [peachey2k2/oniki](https://github.com/peachey2k2/oniki) | Touhou | Open-source bullet-hell RPG in Godot with Touhou-style battles, spellcards, and extra-forgiving hitboxes. |
| [Thargelion/godot-vertical-shooter-demo](https://github.com/Thargelion/godot-vertical-shooter-demo) | Vertical tactical shooter | C# Godot vertical shooter demonstration with basic enemy wave structure. |
| [fabriziosalmi/space23](https://github.com/fabriziosalmi/space23) | Music-driven vertical shooter | Music-driven vertical shoot-'em-up that runs in the browser; Godot 4 + WebAssembly, deployed to GitHub Pages. |
| [naiFeiTian007/space_impact_android](https://github.com/naiFeiTian007/space_impact_android) | Space Impact (Nokia) | Godot 4 Android remake of a Space Impact-style retro shooter with Nokia LCD visuals. |
