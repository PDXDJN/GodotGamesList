# Bullet Hell

Godot repositories for dense bullet-pattern games and the engines that power them.

Last reviewed: 2026-06-20.

## Playable Bullet-Hell Games

| Repository | Notes |
|---|---|
| [SkyanSam/BulletHellTutorial](https://github.com/SkyanSam/BulletHellTutorial) | Godot bullet-hell tutorial project with player, bullet, bullet-spawner, and game-over scenes. Good entry-level reference. |
| [jordycimo/bullethell](https://github.com/jordycimo/bullethell) | Compact GDScript bullet-hell game with player, stamina, UI, and main scenes. |
| [rrdd-repo/GodotBulletHellPrototype](https://github.com/rrdd-repo/GodotBulletHellPrototype) | Unfinished but runnable Godot prototype with movement, shots, resolution switching, characters, and levels. |
| [Trece1101/Bullet-Rain](https://gitlab.com/Trece1101/Bullet-Rain) | GitLab-hosted PC shmup and bullet-hell project made in Godot with GDScript. |
| [djokavex_gamedev/mygames/yabh](https://gitlab.com/djokavex_gamedev/mygames/yabh) | GitLab-hosted "Yet Another Bullet Hell" Godot project. |
| [micahkepe/43-monkeys](https://github.com/micahkepe/43-monkeys) | 2D roguelike/bullet-hell hybrid featuring swarm controls and bullet-hell mechanics in Godot. |
