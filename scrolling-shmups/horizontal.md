# Horizontal Shmups

Godot repositories for R-Type, Gradius, Defender, and side-scrolling shoot-'em-ups.

Last reviewed: 2026-06-20.

| Repository | Inspired by | Notes |
|---|---|---|
| [robotzero/l-well](https://github.com/robotzero/l-well) | R-Type | Godot project with player/enemy bullets, starfield parallax layers, enemies, and level scene. |
| [jardel-codes/SMHUP](https://github.com/jardel-codes/SMHUP) | Side-scrolling shmup | Small Godot shoot-'em-up described as sideways; minimal scope good for structure reference. |
| [liamchristerry/shmup](https://github.com/liamchristerry/shmup) | Horizontal shmup | Simple 2D Godot shoot-'em-up with health, power-ups, and progressive enemy waves. |
| [JSolde/Godot-demo-2D-Side-Scrolling-and-Wraparound-Shooter](https://github.com/JSolde/Godot-demo-2D-Side-Scrolling-and-Wraparound-Shooter) | Defender-like | MIT-licensed Godot 4.2/4.3 demo with side-scrolling and wraparound world examples. |
| [Toxe/godot-defender-clone](https://github.com/Toxe/godot-defender-clone) | Defender | MIT-licensed WIP Defender clone in Godot with side-scrolling survival mechanics. |
| [crystal-bit/space-shooter](https://github.com/crystal-bit/space-shooter) | Side-scrolling shooter | GPL-3.0 Godot 3 shoot-'em-up made for Hacktoberfest 2019; clean and readable source. |
| [HouZenKai/ShooterCarnival](https://github.com/HouZenKai/ShooterCarnival) | Golden-age arcade shmup | Collaborative open-source shoot-'em-up homage to the golden age of arcade shooters. |
| [NexusrexDev/Geoshootria](https://github.com/NexusrexDev/Geoshootria) | Horizontal shmup | Simple 2D horizontal side-scrolling shmup made with Godot Engine. |
| [greenian/boxshmup](https://github.com/greenian/boxshmup) | Horizontal shmup | Shmup made in Godot as a learning exercise. |
| [thelastbucuc/godot-space-ace](https://github.com/thelastbucuc/godot-space-ace) | Space arcade shooter | Arcade space shooter game made with Godot for learning. |
