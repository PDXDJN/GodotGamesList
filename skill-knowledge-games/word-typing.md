# Word and Typing Games

Godot repositories for Wordle clones, typing speed games, and word-based challenges.

Last reviewed: 2026-06-20.

## Wordle and Word Guessing

| Repository | Inspired by | Notes |
|---|---|---|
| [Brawmario/godot-wordle](https://github.com/Brawmario/godot-wordle) | Wordle | Wordle reimplementation in Godot; playable on itch.io. |
| [Awfyboy/Azerdle](https://github.com/Awfyboy/Azerdle) | Wordle | Open-source Wordle clone in Godot 4.3 with multi-resolution support and web/mobile builds. |
| [DiscoveringGodot/2_Loony_Lips](https://github.com/DiscoveringGodot/2_Loony_Lips) | Mad Libs | Mad Libs-style word-fill game built as a Godot GDScript learning project. |
