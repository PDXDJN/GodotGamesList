# Logic and Deduction Puzzles

Godot repositories for Minesweeper, Sudoku, 2048, sliding puzzles, and other deduction-based games.

Last reviewed: 2026-06-20.

## Minesweeper

| Repository | Notes |
|---|---|
| [YeOldeDM/godot-minesweeper](https://github.com/YeOldeDM/godot-minesweeper) | Minesweeper clone built with Godot GUI nodes; good structural reference. |
| [vesas/godot-minesweeper](https://github.com/vesas/godot-minesweeper) | Simple Minesweeper implementation in Godot. |
| [robatron/godot-minesweeper](https://github.com/robatron/godot-minesweeper) | Minesweeper learning project in Godot. |
| [NirajMaharjan007/Minesweeper](https://github.com/NirajMaharjan007/Minesweeper) | Minesweeper implemented in Godot with C#. |
| [genete/Minehunter](https://github.com/genete/Minehunter) | Minesweeper clone made with Godot Engine; classic left-click-to-reveal gameplay. |

## Sudoku

| Repository | Notes |
|---|---|
