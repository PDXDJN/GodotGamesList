# Memory and Pattern

Godot repositories for Simon Says, card-matching memory games, and sequence-recall challenges.

Last reviewed: 2026-06-20.

| Repository | Inspired by | Notes |
|---|---|---|
| [JoeChen2/godot-simon-says](https://github.com/JoeChen2/godot-simon-says) | Simon Says | Simon Says sequence game created with Godot Engine. |
| [8to16apps/Simon](https://github.com/8to16apps/Simon) | Simon | Prototype of the classic Simon colour-sequence game in Godot v3. |
| [Tzoop/Memory-Game-Godot-version-4.1.1.-](https://github.com/Tzoop/Memory-Game-Godot-version-4.1.1.-) | Card memory / Concentration | Card pair-matching memory game made with Godot 4.1.1. |
| [Tzoop/MemoryGame](https://github.com/Tzoop/MemoryGame) | Card memory / Concentration | Earlier card memory game made with Godot Engine 3. |
| [NotEsperix/Memory-Madness-Game](https://github.com/NotEsperix/Memory-Madness-Game) | Card memory | Music-enhanced card-matching game in Godot; goal is to clear all pairs in the fewest moves. |
