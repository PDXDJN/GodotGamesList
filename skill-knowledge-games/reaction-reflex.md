# Reaction and Reflex Games

Godot repositories for Whack-a-Mole, target-tapping, and other reaction-speed challenges.

Last reviewed: 2026-06-20.

| Repository | Inspired by | Notes |
|---|---|---|
| [Kapioga/WhackAMole](https://github.com/Kapioga/WhackAMole) | Whack-a-Mole | Simple Whack-a-Mole arcade game made with Godot Engine 4.2. |
| [GamerNight/Whack-A-Frog](https://github.com/GamerNight/Whack-A-Frog) | Whack-a-Mole | Whack-a-Mole variant (frogs instead of moles) written in GDScript with Godot. |
| [kirbycope/godot-whack-a-mole](https://github.com/kirbycope/godot-whack-a-mole) | Whack-a-Mole | Godot Whack-a-Mole implementation. |
| [HibiscusPoet/Whack-A-Mole](https://github.com/HibiscusPoet/Whack-A-Mole) | Whack-a-Mole | Godot Whack-a-Mole project. |
| [denisarissa/godot-minigames](https://github.com/denisarissa/godot-minigames) | Whack-a-Mole / Flappy Bird | Godot minigame collection including a Whack-a-Mole and other reflex-based games. |
