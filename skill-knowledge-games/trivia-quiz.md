# Trivia and Quiz

Godot repositories for trivia games, quiz engines, and question-and-answer formats.

Last reviewed: 2026-06-20.

| Repository | Notes |
|---|---|
| [Antokolos/know-everything-os](https://github.com/Antokolos/know-everything-os) | "I Know Everything" — crossplatform trivia/quiz game released on Steam, made with Godot; supports controller. |
| [ninjavaz/QuizGameAndroid](https://github.com/ninjavaz/QuizGameAndroid) | Simple quiz game for Android built in Godot with GDScript. |
| [MyNameIsCarsten/GodotSimpleQuiz](https://github.com/MyNameIsCarsten/GodotSimpleQuiz) | Godot quiz with multiple modes, random question ordering, wrong-answer repetition, and JSON import for custom question sets. |
| [dAmihl/GdOpenTdb](https://github.com/dAmihl/GdOpenTdb) | Godot C# plugin that loads questions live from the Open Trivia Database API; useful as a backend for any quiz game. |
| [MatiasVME/QuizNodes](https://github.com/MatiasVME/QuizNodes) | Godot plugin for authoring and presenting customised quizzes inside the editor. |
