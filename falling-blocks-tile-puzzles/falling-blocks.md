# Falling Blocks

Godot repositories for Tetris-style games, Dr. Mario, Puyo Puyo, and other falling-piece puzzles.

Last reviewed: 2026-06-19.

## Tetris and Tetris-Style

| Repository | Inspired by | Notes |
|---|---|---|
| [jpcerrone/PokeTetris](https://github.com/jpcerrone/PokeTetris) | Tetris | Godot 4 modern Tetris clone with SRS, hold, seven-bag, ghost piece, DAS, levels, lines, and scoring. |
| [Sparrowworks/Tetris](https://github.com/Sparrowworks/Tetris) | Tetris | Godot Tetris clone with visual polish and ghost block support. |
| [mstuttgart/tetrim](https://github.com/mstuttgart/tetrim) | Tetris | Minimalist Tetris clone made as a complete Godot learning project. |
| [andrew-wilkes/tetron](https://github.com/andrew-wilkes/tetron) | Tetris | Tutorial-driven Tetris clone with bundled assets and video playlist. |
| [Lordloss90/OpenPuzzleGame](https://github.com/Lordloss90/OpenPuzzleGame) | Tetris | Open-source falling-block puzzle demo. |
| [CamGomezDev/SmartTetris](https://github.com/CamGomezDev/SmartTetris) | Tetris | Tetris with an AI player trained through a genetic algorithm. |
| [nolenroyalty/simple-godot-tetris](https://github.com/nolenroyalty/simple-godot-tetris) | Tetris | Small first-Godot implementation. |
