# Top-Down 2D Racing

Godot repositories for overhead 2D racing games and drifting/steering prototypes.

Last reviewed: 2026-06-20.

| Repository | Inspired by | Notes |
|---|---|---|
| [FernandoH-G/Turtles-Racing](https://github.com/FernandoH-G/Turtles-Racing) | 2D top-down racing | Small 2D Godot racing game with race logic and track scenes. |
| [Cheeseness/tiny-chopper-raceway](https://gitlab.com/Cheeseness/tiny-chopper-raceway) | Top-down drifting | GitLab-hosted Tiny Chopper Raceway example; older Godot source lives under the `godot` folder (uses `engine.cfg`). |
| [37Rb/godot-overhead-car-2d](https://github.com/37Rb/godot-overhead-car-2d) | Overhead car physics | Adds `OverheadCarBody2D` for Godot 4 based on `CharacterBody2D`; a physics component rather than a full game, but the foundation for a top-down racer. |
