# Arcade-Style Racing

Godot repositories for Road Rash combat racing, Hill Climb, OutRun-style, and endless road games.

Last reviewed: 2026-06-20.

| Repository | Inspired by | Notes |
|---|---|---|
| [pranav-dp/rashroad](https://github.com/pranav-dp/rashroad) | Road Rash | Pseudo-3D Godot racing game with on-road combat mechanics and AI opponents. |
| [omarzaafan732/hillclimbracing-godot](https://gitlab.com/omarzaafan732/hillclimbracing-godot) | Hill Climb Racing | GitLab-hosted Godot hill-climb racing project with car, levels, pickups, UI, scripts, and project source. |
| [PowerOlive/arch-racer](https://gitlab.com/PowerOlive/arch-racer) | Endless road racing | GitLab-hosted endless runner/racing simulator with road, lobby, camera, score, and player scenes/scripts. |
| [jrecuero/racing_game](https://github.com/jrecuero/racing_game) | Arcade racing | Older Godot racing-game example with scenes and assets; good reference for basic race logic. |
