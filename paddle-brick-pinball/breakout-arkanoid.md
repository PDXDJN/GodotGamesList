# Breakout and Arkanoid

Godot repositories for Breakout, Arkanoid, and brick-breaking arcade games.

Last reviewed: 2026-06-19.

| Repository | Inspired by | Notes |
|---|---|---|
| [vnen/blockpop](https://github.com/vnen/blockpop) | Breakout | Archived Breakout clone built with Godot Engine 1.1. |
| [YeOldeDM/godot-breakout-example](https://github.com/YeOldeDM/godot-breakout-example) | Breakout / Arkanoid | Simple Godot 2.1.4 example with MIT license. |
| [Sparrowworks/Brick-Breaker](https://github.com/Sparrowworks/Brick-Breaker) | Arkanoid / Breakout | Godot 4 rewrite with a level editor and save/load support. |
| [kazeraniman/BreakoutClone](https://github.com/kazeraniman/BreakoutClone) | Breakout | Breakout clone made in Godot with MIT license. |
| [mikahimself/breakout-godot](https://github.com/mikahimself/breakout-godot) | Breakout | Simple Breakout clone built with Godot Engine. |
| [Una1n/Arkanoid](https://github.com/Una1n/Arkanoid) | Arkanoid | Arkanoid clone made in Godot 4. |
| [kyranet/arkanoid-godot](https://github.com/kyranet/arkanoid-godot) | Arkanoid | Arkanoid implementation written in Godot 4. |
| [visola/bounce](https://github.com/visola/bounce) | Arkanoid / Breakout hybrid | Game blending Arkanoid and Breakout ideas, built with Godot Engine. |
