# Action Roguelites

Godot repositories for real-time roguelites, dungeon crawlers, deckbuilders, and twin-stick roguelite shooters in the tradition of Enter the Gungeon, The Binding of Isaac, and Hades.

Last reviewed: 2026-06-20.

## Action RPG and Dungeon Crawlers

| Repository | Notes |
|---|---|
| [EeroLai/abyssal-walker](https://github.com/EeroLai/abyssal-walker) | Godot 4.6 action RPG prototype built around a beacon-driven abyss-run loop; highest-starred (111★) action roguelite in GDScript. |
| [Infinixius/lucifer-legacy](https://github.com/Infinixius/lucifer-legacy) | Multiplayer hack-'n-slash dungeon crawler roguelite made in Godot; created for a school project. 18★. |
| [Adeon18/Moritur](https://github.com/Adeon18/Moritur) | 2D action roguelike in Godot where dice rolls affect gameplay mechanics. 9★. |
| [ljvmiranda921/abyss](https://github.com/ljvmiranda921/abyss) | Retro action-roguelike game in Godot. 7★. |
| [ltsdw/godot-final-game-project](https://github.com/ltsdw/godot-final-game-project) | Godot game explicitly inspired by Enter the Gungeon and The Binding of Isaac. |
| [quiver-dev/tiny-wizard-demo](https://github.com/quiver-dev/tiny-wizard-demo) | Tiny Wizard Demo using Quiver's top-down shooter template; structured in the style of The Binding of Isaac with room transitions and enemy encounters. |
| [skarstensen/isaac_room_transition](https://github.com/skarstensen/isaac_room_transition) | Sample Godot 4 project explaining Binding of Isaac-style room transitions; useful structural reference. |
