# Auto-Runners

Godot repositories for Temple Run-style 3D runners, side-scrolling endless games, Chrome Dino-likes, and endless helicopter/road games.

Last reviewed: 2026-06-20.

| Repository | Inspired by | Notes |
|---|---|---|
| [NovemberDev/novemberdev-godot-endless-runner-tutorial](https://github.com/NovemberDev/novemberdev-godot-endless-runner-tutorial) | Endless runner | Most-starred (36★) Godot endless runner template; built for a tutorial series and the game "Nov Run." MIT-licensed. |
| [FahadLive/BlastOff](https://github.com/FahadLive/BlastOff) | Casual endless runner | Casual endless runner featuring vector graphics built with Godot 4.2.2. |
| [mujtaba-io/3d-endless-runner](https://github.com/mujtaba-io/3d-endless-runner) | Temple Run | 3D Temple Run-like game made in Godot; tutorial companion project. |
| [christinec-dev/GodotEndlessRunner](https://github.com/christinec-dev/GodotEndlessRunner) | 3D endless runner | Code from a Dock & Roll 3D endless runner series in Godot with procedurally generated levels, obstacles, and collectibles. |
| [AlexNottaBen/Towards-The-Sunrise](https://github.com/AlexNottaBen/Towards-The-Sunrise) | Race the Sun | Arcade game inspired by Race the Sun (2013); minimalist endless runner aesthetic. |
| [kaushalmeena/marble-runner](https://github.com/kaushalmeena/marble-runner) | Endless runner | Godot marble endless runner with dynamic obstacle generation. |
| [zidan-idz/DinoKing](https://github.com/zidan-idz/DinoKing) | Chrome Dino | Casual endless runner for Android inspired by the Chrome browser Dino game, made with Godot 4. |
| [DlegendZ/Google-Dino](https://github.com/DlegendZ/Google-Dino) | Chrome Dino | Godot endless runner inspired by the Google Chrome offline Dino game. |
| [jessejamesblack/endless-helicopter-reborn](https://github.com/jessejamesblack/endless-helicopter-reborn) | Helicopter arcade | Godot 4.6 Android endless helicopter game with upgrades and power-ups. |
