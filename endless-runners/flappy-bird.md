# Flappy Bird

Godot repositories for single-button tap-to-flap endless obstacle games.

Last reviewed: 2026-06-20.

| Repository | Notes |
|---|---|
| [Hernandez712/FlappyBird](https://github.com/Hernandez712/FlappyBird) | Flappy Bird clone in Godot 4.4 with basic 2D mechanics and procedural level generation. |
| [Code-Theft-Auto/Flappy-Bird](https://github.com/Code-Theft-Auto/Flappy-Bird) | Flappy Bird remake in Godot. |
| [i-bardinov/JustFlap](https://github.com/i-bardinov/JustFlap) | Arcade Flappy Bird-style game in Godot 3.2.3; includes score, speed, and simple sound. |
| [the0cp/godot_flappy_bird](https://github.com/the0cp/godot_flappy_bird) | 2D Flappy Bird made with Godot Engine. |
| [anthonygedeon/flappybird](https://github.com/anthonygedeon/flappybird) | Flappy Bird clone made in Godot as a GDScript learning project. |
| [rafidaaziz23/flappy-bird-godot](https://github.com/rafidaaziz23/flappy-bird-godot) | Beginner-friendly Flappy Bird clone in Godot 4.x with physics, scene instancing, and signals. |
| [jvaguiar05/tappy_plane](https://github.com/jvaguiar05/tappy_plane) | Flappy Bird-inspired side-scroller with parallax backgrounds and dynamic obstacle generation. |
| [SirGolem/flying-bird](https://github.com/SirGolem/flying-bird) | Simple Flappy Bird clone in Godot. |
