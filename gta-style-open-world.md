# GTA-Style and Top-Down Open World

Godot resources for building GTA1-style games: top-down open-world driving, on-foot combat, and free-roaming mission structure. No single "GTA1 rebuilt in Godot" repo exists yet; the practical path is to combine a Godot GTA3 reimplementation (for project structure), GTA1 C++ references (for game data and behavior), and Godot 4 component repos (for vehicle and combat systems).

Note: repos here that use original GTA game files require players to supply their own legally owned copy. Do not bundle original Rockstar assets.

Last reviewed: 2026-06-20.
